A program that writes one haiku about debugging — three lines in the 5-7-5 syllable shape — to `/output/entry.txt`.

> A breakpoint at three
> the watch window shows my name
> the suspect was me

The haiku was drafted from six candidates and picked for the sharpest concrete picture (a breakpoint at 3am, the debugger's watch window) and the hardest turn in the last line: the hunt for the bug ends with the debugger as the suspect.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. Writes `/output/entry.txt` (72 characters, three lines, 5-7-5 syllables).
